# Spec compliance — bunker

This server's standing against the estate's canonical MCP compliance
checklist, from the MCP Inspector sweep of 2026-10-20 (Inspector CLI
2.11.0, both protocol eras). The canonical checklist — every row's
requirement, era, level, and specification link — is maintained in
the estate's conformance records alongside the sweep's raw evidence;
this file reproduces its rows with this server's status per row. The
same table is published at https://qompass.ai/solutions/mcp/bunker/

**Standing.** Not probed in the 2026-10-20 Inspector sweep. Not built — the Stage C MCP server is under construction.

Status vocabulary: **Pass** (evidence satisfies the row) · **Partial**
(partly adopted) · **Gap** (evidence shows the row unmet) · **Not
applicable** (the row's feature or transport is not in play for this
server) · **Not probed** (the sweep's evidence neither passes nor
fails the row).
